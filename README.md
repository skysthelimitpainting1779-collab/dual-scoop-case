# Dual Scoop Case

Print-ready dual scoop clamshell case modeled from the physical product photos.

## Files

| File | Description |
|------|-------------|
| `dual_scoop_v3.scad` | Parametric OpenSCAD source |
| `PRINT_full_open_case.stl` | **Recommended** – full case opened flat with living hinge |
| `PRINT_scoop.stl` | Removable scoop piece (print **2**) |
| `dual_scoop_full.glb` | Full scene for 3D viewing |
| `dual_scoop_case.glb` | Case only (GLB) |
| `scoop.glb` | Single scoop (GLB) |

## Print Settings (Dremel / FDM)

- **Material**: PETG preferred (better hinge flex). PLA is stiffer.
- Layer height: 0.16–0.2 mm
- Walls: 3–4
- Infill: 15–25%
- Supports: none needed
- Print the full open case flat on the bed

## Dimensions
- Overall length ≈ 100 mm
- Closed width ≈ 42 mm
- Closed height ≈ 17 mm
- Scoop bowls Ø 18 mm
